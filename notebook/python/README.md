# Supporting math sources

The current guide is `../notebook.tex`, built as `../notebook.pdf`.
This directory provides the shared number-theory, graph-counting and
sums/probability LaTeX sources, plus their bibliography in `SOURCES.md`.

The previous standalone Python project and BAPC print PDFs are archived in
`../legacy/`. There is one active NWERC guide; use its main source for edits.
`build.sh` remains a compatibility entry point for the unified build.
