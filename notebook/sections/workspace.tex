\section{Workspace and setup}\label{setup:workspace}
Use Bash. Create a workspace, then save the two templates below in
\texttt{tmpl/} before running \texttt{tmpl}.
\begin{lstlisting}[language=bash]
mkdir -p contest/tmpl
cd contest
\end{lstlisting}

\hint{\texttt{dbg(...)} writes to stderr, so debugging stays visible when
answers go to a file. \texttt{rp}/\texttt{rc} enable it locally.
Python: \texttt{dbg(f"\{n=\}")}; C++: \texttt{dbg(n);}
(C++ values must support streaming; loop over containers).
Submit \texttt{A/py.py} or \texttt{A/cpp.cpp}.}

\hint{For practice with this repo available:
\texttt{source /path/to/ICPC-Setup/setup.sh .}
copies the templates and enables the commands.}

\par\noindent\begin{minipage}{\linewidth}
\subsection{Create and run}\label{setup:debug}
\begin{lstlisting}[language=bash]
tmpl                  # copy tmpl/ into A-N
rp A                  # Python, terminal input
rc A                  # compile and run C++
rp A 1                # reads A/1.in
rc A 1
tp A                  # test Python on all A/*.in
tc A                  # compile once, test all C++
\end{lstlisting}
\end{minipage}\par
\hint{\texttt{tmpl} keeps existing files. Letters accept either case.
\texttt{rp A sample} reads \texttt{A/sample.in}; no input argument uses stdin.}
