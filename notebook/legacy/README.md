# Previous BAPC material

These PDFs preserve the printed BAPC notebook and its later Python supplement.
They are historical snapshots, not the current NWERC print guide.

- `bapc-2026.pdf`: original C++ notebook, including the old notes sheet.
- `python-supplement-2026.pdf`: last Python/mathematics supplement and cover.
- `bapc-combined-2026.pdf`: earlier combined BAPC print copy.
- `bapc.tex`: original main source; supporting sections and tested snippets
  remain in `../sections/` and `../code/`.
- `python/`: the former standalone supplement's source snapshot, with its
  template/helper dependencies in `code/`.

For preparation and printing, use `../notebook.tex` and `../notebook.pdf`.
